Если видите ошибку:
  "E: dpkg was interrupted, you must manually run..."

Выполните эти 3 команды:

  1. sudo dpkg --configure -a
  2. sudo apt --fix-broken install
  3. sudo apt update

Затем запустите скрипт снова:

  cd ~/projects/TG_BOT-AdmissionSum
  bash QUICK_DEPLOY.sh
