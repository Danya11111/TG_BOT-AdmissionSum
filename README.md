## 🆕 Версия 2.0 - Улучшенная обработка ошибок

### Что нового:

#### 1. 🔄 Retry-логика
Автоматические повторные попытки при временных сбоях API:
- До 3 попыток с exponential backoff
- Обработка Timeout, ConnectionError, HTTPError
- Детальное логирование каждой попытки

#### 2. 🛡️ Fallback-механизм
Многоуровневая система отказоустойчивости:
```
Вопрос → RAG-поиск → GigaChat (с retry) → Fallback на RAG → Ответ пользователю
```
Теперь пользователь **всегда получает ответ**, даже если GigaChat недоступен!

#### 3. 📊 Логирование
Полная прозрачность работы бота:
- Логи в файл `bot.log` и в консоль
- Уровни: INFO, WARNING, ERROR
- Логирование всех операций: RAG-поиск, API запросы, ошибки

#### 4. 💬 Улучшенные сообщения
Специфичные сообщения для каждого типа ошибки:
- ⏱️ Timeout → "Превышено время ожидания" + RAG-фрагменты
- 🔌 Connection Error → "Ошибка подключения" + контакты
- 🔐 HTTP 401 → "Ошибка авторизации сервиса"
- ⏳ HTTP 429 → "Превышен лимит запросов"

## Быстрый старт (Telegram + GigaChat)

1. Создайте файл `.env` по образцу `.env.example` и заполните:
   - `TELEGRAM_BOT_TOKEN` — токен бота из BotFather
   - `GIGACHAT_AUTH_BASIC` — Base64("client_id:client_secret") из портала GigaChat
2. Установите зависимости:
```bash
pip install -r requirements.txt
```
3. Запустите бота:
```bash
python main.py
```

Если `GIGACHAT_AUTH_BASIC` не указан, бот будет работать без интеллектуальных ответов (фиксированные кнопки и справка).

## Построение локальной базы знаний (RAG)

Директории:
- `data/guu/raw/` — очищенные тексты страниц (по доменам `guu.ru`, `priem.guu.ru`)
- `data/guu/chunks/` — чанки по 500–800 слов
- `data/guu/index.json` — индекс для поиска

Шаги:
1. Сбор и очистка страниц + разбиение на чанки и индекс:
```bash
python rag_build.py --max-pages 200 --delay 0.2
```
2. Проверка поиска (опционально):
```python
from rag_search import RagSearcher
s = RagSearcher()
for line in RagSearcher.format_context(s.search("документы для поступления", top_k=5)):
    print(line)
```

Интеграция:
- При наличии `data/guu/index.json` бот добавляет Top‑K найденных фрагментов в `RAG_CONTEXT` системного промпта при обращении к GigaChat.

Примечания:
- Уважайте сайт: используйте `--delay` при массовой индексации.
- Для PDF/сканов потребуется расширение пайплайна (не входит в базовую версию).

## 🐛 Troubleshooting

### Проблема: Частые timeout
**Решение:** Увеличьте `request_timeout_sec` и `retry_delay_sec`

### Проблема: ConnectionError
**Решение:** Проверьте подключение к интернету и доступность API

### Проблема: HTTP 401
**Решение:** Проверьте `GIGACHAT_AUTH_BASIC` в `.env`

### Проблема: Низкий score в RAG
**Решение:** Обновите базу знаний и перезапустите `rag_build.py`
