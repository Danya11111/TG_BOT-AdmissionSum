# 🚨 Что делать прямо сейчас на сервере

## Текущая ситуация

Вы видите две проблемы:
1. **PAM configuration dialog** - нужно ответить
2. **Python 3.11 не найден** - Ubuntu 24.04 использует Python 3.12

## Быстрое решение (выполните на сервере)

### Шаг 1: Закройте PAM диалог

Если диалог еще открыт:
- Нажмите `Tab` чтобы выбрать "Yes"
- Нажмите `Enter`

Или нажмите `Ctrl+C` чтобы прервать текущую команду.

### Шаг 2: Исправьте проблемы и установите Python 3.12

```bash
# 1. Исправление dpkg (если еще не сделано)
sudo dpkg --configure -a
sudo apt --fix-broken install

# 2. Установка Python 3.12 и зависимостей (для Ubuntu 24.04)
export DEBIAN_FRONTEND=noninteractive
sudo apt update
sudo apt install -y python3.12 python3.12-venv python3-pip git curl wget docker.io docker-compose

# 3. Запуск Docker
sudo systemctl start docker
sudo systemctl enable docker
```

### Шаг 3: Запустите обновленный скрипт

```bash
cd ~/projects/TG_BOT-AdmissionSum

# Обновите скрипт из Git (если нужно)
git pull origin develop

# Запустите скрипт
bash QUICK_DEPLOY.sh
```

Скрипт теперь:
- ✅ Автоматически определит Python 3.12
- ✅ Обработает PAM диалог автоматически
- ✅ Установит все зависимости

## Если скрипт все еще не работает

Выполните шаги вручную:

```bash
cd ~/projects/TG_BOT-AdmissionSum

# 1. Создание виртуального окружения
python3.12 -m venv venv
source venv/bin/activate

# 2. Установка зависимостей Python
pip install --upgrade pip
pip install -r requirements.txt

# 3. Настройка .env
cp .env.example .env
nano .env
# Заполните TELEGRAM_BOT_TOKEN и GIGACHAT_AUTH_BASIC

# 4. Запуск Qdrant
docker-compose up -d

# 5. Миграция данных
python process_guu_docs.py

# 6. Создание systemd сервиса
sudo nano /etc/systemd/system/guu-bot.service
```

Вставьте в файл (замените `root` на вашего пользователя):

```ini
[Unit]
Description=GUU Telegram Bot
After=network.target docker.service
Requires=docker.service

[Service]
Type=simple
User=root
Group=root
WorkingDirectory=/root/projects/TG_BOT-AdmissionSum
Environment="PATH=/root/projects/TG_BOT-AdmissionSum/venv/bin"
ExecStart=/root/projects/TG_BOT-AdmissionSum/venv/bin/python3 main.py
Restart=always
RestartSec=10
StandardOutput=journal
StandardError=journal

[Install]
WantedBy=multi-user.target
```

Сохраните: `Ctrl+O`, `Enter`, `Ctrl+X`

```bash
# 7. Запуск сервиса
sudo systemctl daemon-reload
sudo systemctl enable guu-bot
sudo systemctl start guu-bot
sudo systemctl status guu-bot
```

## Проверка работы

```bash
# Логи в реальном времени
sudo journalctl -u guu-bot -f

# Статус
sudo systemctl status guu-bot
```

## Важно

- Ubuntu 24.04 использует **Python 3.12**, а не 3.11
- Проект совместим с Python 3.12
- Скрипт теперь автоматически определяет версию Python
