# Настройка сохранения запросов пользователей и обработки документов из GUU_docs

## Что было добавлено

### 1. Сохранение запросов пользователей
- Все запросы пользователей теперь сохраняются в отдельную коллекцию Qdrant `user_queries`
- Запросы векторизуются и могут использоваться для поиска похожих вопросов
- При ответе на вопрос бот ищет похожие запросы других пользователей для улучшения контекста

### 2. Обработка всех документов из GUU_docs
- Создан скрипт `process_guu_docs.py` для обработки всех PDF, DOCX и XLSX файлов из папки `GUU_docs`
- Документы разбиваются на чанки и векторизуются
- Все чанки загружаются в коллекцию `guu_documents` в Qdrant

## Установка и настройка

### Шаг 1: Убедитесь, что установлены все зависимости

```bash
pip install -r requirements.txt
```

### Шаг 2: Запустите Qdrant

```bash
docker-compose up -d
```

### Шаг 3: Обработайте все документы из GUU_docs

```bash
python process_guu_docs.py
```

Этот скрипт:
- Обработает все PDF, DOCX и XLSX файлы из папки `GUU_docs`
- Извлечет текст из каждого документа
- Разобьет текст на чанки (~500 слов каждый)
- Векторизует чанки и загрузит их в Qdrant

**Важно:** Скрипт добавляет документы в существующую коллекцию `guu_documents`. Если коллекция не существует, сначала запустите:

```bash
python rag_build_vector.py
```

### Шаг 4: Запустите бота

```bash
python main.py
```

Бот автоматически:
- Создаст коллекцию `user_queries` для сохранения запросов пользователей
- Будет сохранять все запросы и ответы пользователей
- Будет использовать сохраненные запросы для улучшения ответов

## Как это работает

### Сохранение запросов

Когда пользователь задает вопрос:
1. Запрос векторизуется
2. Сохраняется в коллекцию `user_queries` вместе с ответом бота
3. При следующих похожих запросах бот может использовать сохраненные ответы как дополнительный контекст

### Обработка документов

Скрипт `process_guu_docs.py`:
1. Сканирует папку `GUU_docs`
2. Для каждого файла:
   - PDF → извлекает текст через PyPDF2
   - DOCX → извлекает текст через python-docx
   - XLSX → извлекает данные через pandas/openpyxl
3. Разбивает текст на чанки
4. Векторизует чанки через локальную модель embeddings
5. Загружает в Qdrant

## Структура данных

### Коллекция `user_queries`

Каждый запрос сохраняется с метаданными:
- `user_id`: ID пользователя Telegram
- `query`: Текст запроса
- `response`: Ответ бота
- `timestamp`: Время запроса
- `type`: "user_query"
- `has_rag_context`: Была ли использована RAG-информация
- `fallback`: Был ли использован fallback-режим

### Коллекция `guu_documents`

Каждый чанк документа содержит:
- `chunk_id`: Уникальный ID чанка
- `title`: Название файла
- `source`: Путь к файлу (например, "GUU_docs/файл.pdf")
- `content`: Текст чанка
- `file_type`: Тип файла (pdf, docx, xlsx)

## Параметры скрипта process_guu_docs.py

```bash
python process_guu_docs.py --help
```

Доступные параметры:
- `--docs-dir`: Путь к папке с документами (по умолчанию: `GUU_docs`)
- `--collection`: Название коллекции в Qdrant (по умолчанию: `guu_documents`)
- `--batch-size`: Размер батча для векторизации (по умолчанию: 20)

Пример:
```bash
python process_guu_docs.py --docs-dir GUU_docs --collection guu_documents --batch-size 30
```

## Проверка работы

### Проверка коллекции user_queries

Откройте Qdrant Dashboard: http://localhost:6333/dashboard

Вы должны увидеть коллекцию `user_queries` после первого запроса пользователя.

### Проверка загруженных документов

После выполнения `process_guu_docs.py` проверьте коллекцию `guu_documents` в Qdrant Dashboard. Там должны быть все чанки из документов папки `GUU_docs`.

## Устранение проблем

### Ошибка "Коллекция не найдена"

Если при запуске `process_guu_docs.py` возникает ошибка о том, что коллекция не найдена:
1. Сначала запустите `python rag_build_vector.py` для создания коллекции
2. Затем запустите `python process_guu_docs.py`

### Ошибка при чтении PDF/DOCX

Убедитесь, что установлены библиотеки:
```bash
pip install PyPDF2 python-docx openpyxl pandas
```

### Ошибка при сохранении запросов

Проверьте, что Qdrant запущен:
```bash
docker ps | grep qdrant
```

Если контейнер не запущен:
```bash
docker-compose up -d
```

## Примечания

- Документы из `GUU_docs` добавляются в существующую коллекцию, не заменяя её
- Если нужно пересоздать коллекцию с нуля, удалите её в Qdrant Dashboard и запустите миграцию заново
- Запросы пользователей сохраняются автоматически при каждом ответе бота
- Похожие запросы используются как дополнительный контекст, но не заменяют поиск по документам
