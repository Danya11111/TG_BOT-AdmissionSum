# 🔧 Решение проблемы: "No such file or directory"

Если вы видите ошибку:
```
-bash: cd: /root/projects/TG_BOT-AdmissionSum: No such file or directory
```

Это означает, что проект еще не загружен на сервер. Выполните следующие команды:

## Быстрое решение

```bash
# 1. Создайте директорию для проектов
mkdir -p ~/projects
cd ~/projects

# 2. Клонируйте проект с GitHub (ветка develop)
git clone -b develop https://github.com/Danya11111/TG_BOT-AdmissionSum.git TG_BOT-AdmissionSum

# 3. Перейдите в директорию проекта
cd TG_BOT-AdmissionSum

# 4. Запустите скрипт автоматического развертывания
bash QUICK_DEPLOY.sh
```

## Что дальше?

После выполнения скрипта:

1. **Настройте .env файл:**
   ```bash
   nano .env
   ```
   Заполните:
   - `TELEGRAM_BOT_TOKEN` - получите у @BotFather в Telegram
   - `GIGACHAT_AUTH_BASIC` - Base64 кодированные credentials

2. **Перезапустите бота:**
   ```bash
   sudo systemctl restart guu-bot
   ```

3. **Проверьте статус:**
   ```bash
   sudo systemctl status guu-bot
   ```

## Если Git не установлен

Если команда `git` не найдена, сначала установите Git:

```bash
sudo apt update
sudo apt install -y git
```

Затем выполните команды выше.

## Альтернатива: Загрузка через SCP

Если Git недоступен, загрузите проект с вашего компьютера:

**На вашем компьютере (Windows PowerShell):**
```powershell
cd "C:\Users\Daniil Arkhipov\Desktop\TG_bot"
scp -r TG_BOT-AdmissionSum root@82.202.169.214:~/projects/
```

**Затем на сервере:**
```bash
cd ~/projects/TG_BOT-AdmissionSum
bash QUICK_DEPLOY.sh
```
