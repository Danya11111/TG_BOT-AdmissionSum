# 🚀 Быстрый старт - Развертывание на сервере

## Краткая инструкция для сервера Ubuntu 24.04

### 1. Подключитесь к серверу
```bash
ssh root@82.202.169.214
```

### 2. Загрузите проект на сервер через Git

**На сервере:**
```bash
mkdir -p ~/projects
cd ~/projects
git clone -b develop https://github.com/Danya11111/TG_BOT-AdmissionSum.git TG_BOT-AdmissionSum
cd TG_BOT-AdmissionSum
```

**Альтернатива:** Используйте SCP или WinSCP для загрузки папки `TG_BOT-AdmissionSum`

### 3. На сервере выполните быстрый деплой

**Вариант А: Автоматический (скрипт сам клонирует проект):**
```bash
cd ~
bash <(curl -s https://raw.githubusercontent.com/Danya11111/TG_BOT-AdmissionSum/develop/QUICK_DEPLOY.sh)
```

**Вариант Б: Вручную (если уже клонировали):**
```bash
cd ~/projects/TG_BOT-AdmissionSum
bash QUICK_DEPLOY.sh
```

**Или вручную:**

```bash
# Установка зависимостей
sudo apt update
sudo apt install -y python3.11 python3.11-venv python3-pip docker.io docker-compose

# Создание виртуального окружения
python3.11 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

# Настройка .env
cp .env.example .env
nano .env  # Заполните токены!

# Запуск Qdrant
docker-compose up -d

# Миграция данных
python process_guu_docs.py

# Создание systemd сервиса (см. DEPLOY_TO_SERVER.md)
# Запуск бота
sudo systemctl start guu-bot
```

### 4. Настройте .env файл

Откройте `.env` и заполните:
- `TELEGRAM_BOT_TOKEN` - получите у @BotFather
- `GIGACHAT_AUTH_BASIC` - Base64 кодированные credentials

### 5. Проверьте работу

```bash
# Логи
sudo journalctl -u guu-bot -f

# Статус
sudo systemctl status guu-bot
```

## ⚠️ Если возникла ошибка dpkg

Если при запуске скрипта вы видите:
```
E: dpkg was interrupted, you must manually run 'sudo dpkg --configure -a'
```

Выполните:
```bash
sudo dpkg --configure -a
sudo apt --fix-broken install
```

Затем запустите скрипт снова: `bash QUICK_DEPLOY.sh`

**Подробнее:** См. `ИСПРАВЛЕНИЕ_DPKG.md`
