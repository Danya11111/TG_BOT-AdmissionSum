## 🚀 Как это работает

### Процесс обработки вопроса пользователя

1. **Вопрос пользователя** → Telegram бот
2. **RAG-поиск** → Поиск 3-5 наиболее релевантных фрагментов из 268 документов
3. **Контекст** → Передача найденных фрагментов в GigaChat
4. **Генерация ответа** → GigaChat формирует ответ на основе официальных документов
5. **Ответ пользователю** → С указанием источников

### Пример работы

**Вопрос**: "Какие вступительные экзамены нужно сдавать для поступления в магистратуру?"

**Система**:
1. Находит релевантные фрагменты из документов (например, "Перечень-вступительных-испытаний-на-направления-подготовки-Магистратура")
2. Передает контекст в GigaChat
3. GigaChat формирует ответ на основе РЕАЛЬНЫХ данных из документов
4. Добавляет ссылки на источники

## 🔧 Техническая информация

### Параметры чанкирования
- Размер чанка: ~700 слов (target)
- Минимальный размер: 500 слов
- Перекрытие (overlap): 60 слов

### Поиск
- Метод: TF-IDF + Cosine Similarity
- Top-K: 3 фрагмента по умолчанию
- Матрица: 268 x 50000 (документы x признаки)

### Файлы и папки
```
data/guu/
├── raw/                    # Сырой текст документов
│   ├── [веб-страницы].txt
│   └── [PDF и DOCX].txt
├── chunks/                 # Фрагменты для поиска
│   ├── chunk000001.txt
│   ├── ...
│   └── chunk000268.txt
└── index.json             # Индекс для RAG-поиска
```

## 🔄 Обновление данных

Если нужно добавить новые документы:

1. Поместите PDF/DOCX файлы в папку `GUU_docs`
2. Запустите скрипт обработки:
   ```bash
   python process_documents.py
   ```
3. Перезапустите бота:
   ```bash
   python main.py
   ```
