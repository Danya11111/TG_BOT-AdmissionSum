## 🔧 Если что-то не работает

### Проблема: Бот не находит новые данные

**Решение**: Убедитесь, что файл `data/guu/index.json` содержит 268 записей:

```powershell
# Проверить количество записей в индексе
python -c "import json; data = json.load(open('data/guu/index.json', encoding='utf-8')); print(f'Записей в индексе: {len(data)}')"
```

Должно вывести: `Записей в индексе: 268`

### Проблема: Ошибки при импорте библиотек

**Решение**: Переустановите зависимости:

```powershell
pip install --upgrade PyPDF2 python-docx
```

### Проблема: RAG_SEARCHER не инициализирован

**Решение**: Проверьте, что файл `data/guu/index.json` существует и не пустой.
