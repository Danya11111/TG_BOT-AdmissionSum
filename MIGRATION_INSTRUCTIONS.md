# 🚀 Инструкция по миграции на векторную БД

## Шаг 1: Установка зависимостей

```bash
pip install -r requirements.txt
```

Это установит `qdrant-client` и другие зависимости.

## Шаг 2: Запуск Qdrant

### Вариант A: Docker Compose (рекомендуется)

```bash
docker-compose up -d
```

Проверка работы:
- Откройте http://localhost:6333/dashboard
- Должна открыться веб-панель Qdrant

### Вариант B: Docker напрямую

```bash
docker run -p 6333:6333 -p 6334:6334 \
    -v $(pwd)/qdrant_storage:/qdrant/storage:z \
    qdrant/qdrant
```

### Вариант C: Без Docker

Скачайте бинарник с https://github.com/qdrant/qdrant/releases и запустите локально.

## Шаг 3: Настройка переменных окружения

Добавьте в ваш `.env` файл:

```env
# Qdrant настройки
QDRANT_HOST=localhost
QDRANT_PORT=6333
QDRANT_COLLECTION_NAME=guu_documents

# GigaChat (должны быть уже настроены)
GIGACHAT_AUTH_BASIC=your_base64_credentials
GIGACHAT_SCOPE=GIGACHAT_API_PERS
GIGACHAT_VERIFY_TLS=true
```

## Шаг 4: Миграция данных

Запустите скрипт миграции:

```bash
python rag_build_vector.py
```

**Что делает скрипт:**
1. Загружает существующие чанки из `data/guu/index.json`
2. Векторизует каждый чанк через GigaChat Embeddings API
3. Создает коллекцию в Qdrant
4. Загружает векторы + метаданные в Qdrant

**Время выполнения:**
- Зависит от количества чанков (~762)
- Примерно 10-20 минут (с учетом задержек между запросами к API)

**Прогресс:**
Скрипт показывает прогресс в консоли:
```
Загружено 762 чанков
Векторизация батча 1 (10 текстов)...
Обработано 10/762 чанков (1%)
...
✅ Миграция завершена!
   Коллекция: guu_documents
   Точек в коллекции: 762
   Размерность векторов: 1024
```

## Шаг 5: Запуск бота

После успешной миграции запустите бота:

```bash
python main.py
```

Бот автоматически:
- Подключится к Qdrant
- Проверит наличие коллекции
- Будет использовать векторный поиск для всех запросов

## Проверка работы

1. **Проверка Qdrant:**
   - Откройте http://localhost:6333/dashboard
   - Должна быть коллекция `guu_documents` с 762 точками

2. **Тест поиска:**
   - Запустите бота
   - Задайте вопрос через Telegram
   - Бот должен найти топ-10 релевантных документов и сгенерировать ответ

## Устранение проблем

### Ошибка: "Коллекция не найдена"
**Решение:** Запустите миграцию: `python rag_build_vector.py`

### Ошибка: "Ошибка подключения к Qdrant"
**Решение:** 
- Убедитесь, что Qdrant запущен: `docker-compose ps`
- Проверьте порты: `netstat -an | grep 6333`

### Ошибка: "GigaChat embeddings failed"
**Решение:**
- Проверьте `GIGACHAT_AUTH_BASIC` в `.env`
- Проверьте лимиты API GigaChat
- Увеличьте задержку между батчами в `rag_build_vector.py`

### Медленная векторизация
**Решение:** Это нормально. Векторизация ~762 чанков занимает время из-за лимитов API.

## Откат к старой системе

Если нужно вернуться к старой системе (TF-IDF + JSON):

1. В `main.py` замените:
   ```python
   from rag_search_vector import VectorRagSearcher
   ```
   на:
   ```python
   from rag_search import RagSearcher
   ```

2. Обновите инициализацию:
   ```python
   RAG_SEARCHER = RagSearcher()
   ```

3. В `ask_gigachat` верните `top_k=3` вместо `top_k=10`

## Обновление данных

При добавлении новых документов:

1. Обновите `data/guu/index.json` (через `rag_build.py`)
2. Запустите миграцию снова (скрипт спросит, пересоздать ли коллекцию)

Или создайте инкрементальный скрипт для добавления только новых чанков.
